# superPM Workbench 1.3.0

日期：2026-11-21。应用版本 `1.3.0`，数据库 schema `27`，更新器 `1.1.3`。

本版新增项目管理，将团队成员、需求、执行任务、交付验收和项目资料放到同一条工作主线上，同时保留个人需求、每日安排、会议和便签。

## 新增功能

- 项目创建、自动编号、成员与角色管理，以及“我负责的”“我参与的”和归档视图。概览展示目标、范围、执行与验收进度、逾期／阻塞、待处理事项、项目工时和最近动态。
- 项目需求与全局需求筛选。已有私人需求保持私有，经过预览和明确确认后，才把整棵主子需求树共享到项目；成员移除后立即撤销访问。超管可读取项目，但写入仍受项目角色约束。
- 跨日项目任务，可关联需求、分配执行人和确认人，支持完成说明、提交确认、退回与重提，并可安排到自己的每日任务。项目仅汇总明确关联的工时，个人日程不会自动公开。
- 默认交付与多批次交付，按叶子需求确认范围，保留范围修订和验收轮次；支持证据、延期／豁免、阻断问题及风险接受、结项检查、重新开启和归档。任务完成和需求上线不会自动替代交付验收。
- 项目资料、纪要、决策和外链，以及需求产出物的权限内聚合。私人会议经明确确认后才能复制为独立项目纪要；不会因关联项目需求自动共享。
- 共享编辑增加版本冲突提示与草稿保护；保存过程中继续输入、切换详情和关闭页签时，保留尚未保存的修改。

## 修复

- 更新器停止 HTTP 服务前核验进程身份，强制结束前再次确认；按实际数据库和工作区目录备份、迁移与回滚，保留配置优先级及相对／绝对路径形式；回滚前校验备份，缺少或损坏时明确失败。命令输出等待完整读取后才解析。
- 优化点保存保留请求期间的新输入，旧详情响应不能改写已切换的页面。
- 便签刷新同步干净字段、保留本地修改；保存失败时支持重试、离开保护与按账号隔离的会话草稿恢复，远端已删除的便签仍保留草稿处理入口。
- 空备份列表正常显示备份目录，不再把展示路径当成空备份 ID。另修正需求资源访问与引用、保存冲突和计时边界的相关问题。

## 升级前必读

**本版要求更新器至少为 1.1.3。1.1.2 及更早更新器不能直接执行本次增量升级。** 普通更新包只替换 `app/`，不会更新 `bin/updater.mjs`；不能通过反复点击应用内更新获得此修复。

推荐使用完整包：

1. 保存编辑内容，在所有 AI 客户端断开 superPM MCP，运行旧安装的 `Stop.cmd` 并确认无更新任务。用 `SuperPM.cmd --home` 记录实际数据根，先独立备份数据根和旧程序，保留自定义路径及 `.env` 设置。
2. 解压 `superpm-workbench-1.3.0-win-x64.zip`，用程序文件覆盖原安装目录，或改用新目录并同步 MCP 启动路径。继续使用原数据根、配置指针及路径设置；不要覆盖、删除或迁移数据库、`workspace/`、个人原型。完整包同步更新更新器和安装元数据。
3. 运行 `SuperPM.cmd`，检查原有需求和文件，以及应用 `1.3.0`、更新器 `1.1.3`，再重连 MCP。首次启动会依次执行尚未应用的迁移；从 1.2.0 升级时 schema 由 21 升至 27。不要用旧程序直接打开已升级数据库。

也可先下载 `superpm-mcp-updater-repair-1.3.0.zip`，停机并备份原 `bin/updater.mjs` 后，将修复包内已打包的 `updater.mjs` 复制到该位置，再在安装目录执行：

```powershell
Update.cmd --manifest https://github.com/WangPeng3215/superpm-workbench/releases/download/v1.3.0/update-manifest.json
```

仅在明确允许结束残余 MCP 时加 `--force`。手工替换更新器不会刷新 `install.json`，因此应用内可能继续按旧元数据提示版本不足；这条路径请使用命令行，需要同步元数据时使用完整包。不要直接复制仓库源码代替修复包。

## 兼容性与边界

- 本次数据库迁移为 `0022`—`0027`，保留旧需求、编号和文件。更新器升级会先创建备份，迁移或健康检查失败时尝试回滚；备份不可用时报告 `rollback-failed`，应保留日志和失败目录再手动恢复。完整包覆盖属于手工安装，请务必先完成独立备份。
- MCP 数量不变：默认 16 个工具，启用写入后 32 个。当前 stdio 没有可信项目账号身份，项目共享需求及资源默认拒绝访问，没有新增项目 MCP 工具。
- 便签草稿使用浏览器 `sessionStorage`，用于当前会话重新加载恢复，不是永久备份；尚未被刷新观察到的同字段并发写仍沿用原有后写覆盖语义。
- Windows x64 提供完整安装包、增量包、更新器修复包、可选 AI Skill 包和更新清单。包中不含用户数据库、工作区或个人原型；Linux 继续按源码部署流程升级。
