- 更新状态测试仅固定系统命令边界的成功身份响应，继续执行真实身份比对、登记读取与更新服务；新增查询抛出 `ETIMEDOUT` 时保留过期登记、阻止普通更新、没有下载和更新器启动的用例。先用该边界故障确定复现原断言失败，再验证成功和未知两个分支。真实系统进程测试继续由 shared MCP runtime 测试承担。
