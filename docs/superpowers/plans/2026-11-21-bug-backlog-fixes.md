**目标：**修复 BUG-001/002/005/006/007/011，保留当前项目管理 V1 的全部工作。

**范围：**更新器进程核验与数据路径、优化点保存、便签刷新与失败草稿、备份 CLI 空列表。使用临时目录和专用测试进程验证，不操作真实安装或个人原型，不提交、推送或发布。

- [x] BUG-002：更新器按应用相同的环境优先级确定数据库和工作区，保存更新前实际目标与配置形式；备份成功并校验后才替换程序，回滚恢复实际目标并准确报告失败。回归覆盖相对目录、绝对目录、`.env` 与进程覆盖、后续正常启动、迁移失败、备份损坏及无备份场景。
- [x] BUG-005：在优化点详情保留保存期间的新修订和脏状态；浏览器挂起首次 PATCH，继续输入，释放旧响应，再保存并刷新核验第二版；补充旧请求跨详情成功/失败时的隔离。
- [x] BUG-006：便签无本地草稿时同步刷新结果，只提交修改字段；覆盖外部刷新、同字段冲突、本地未保存输入及旧列表晚于成功保存的场景。

- [x] BUG-011：普通空备份列表显示备份根目录并成功退出；具体备份 ID 校验继续拒绝空值和越界。
